# ☁️ Mochi's First Portfolio

A cute, interactive portfolio website for **Mochi**, an original baby cloud character who is learning how to rain.

Built for the haX.baby "Baby's First Website" hackathon (Track 2: Your Own Baby).

**Live site:** https://tarini-codes.github.io/mochi-portfolio/

## Character sheet
- **Name:** Mochi
- **What I am:** A baby cloud: soft, round, very ticklish, and curious about everything.
- **What I do:** I make tiny weather: drizzles, puddles, lullabies and rainbows.
- **My story:** I formed from a morning mist on a sunny hill. Now I'm learning to rain, one drop at a time.
- **Tagline:** small ideas. brighter beginnings.

## Features
- Tap Mochi for a giggle and a squish
- Eyes that follow your cursor
- A sky that changes from morning to dusk as you scroll
- Toy-block project cards you can open
- "Make it rain" button with a rainbow
- Sound mute toggle (top right)
- A hidden Easter egg: find the tiny star ✦
- Mobile-friendly layout

## Built with
HTML, CSS, JavaScript, SVG, Web Audio API, GitHub Pages
